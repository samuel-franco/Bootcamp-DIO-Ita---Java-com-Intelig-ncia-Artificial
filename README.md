# Bootcamp DIO Itaú - Java com Inteligência Artificial
# 🚀 Jornada Java & IA - Bootcamp Itaú (DIO)

Este repositório contém a organização dos meus estudos, anotações, códigos e projetos desenvolvidos ao longo do **Bootcamp Itaú - Java com Inteligência Artificial** na DIO.

---

## 🎯 Objetivos
- [x] Dominar a sintaxe e os fundamentos do Java Orientado a Objetos.
- [ ] Construir APIs RESTful com Spring Boot.
- [ ] Integrar aplicações Java com ferramentas e APIs de Inteligência Artificial.
- [ ] Aplicar boas práticas de código, versionamento com Git/GitHub e testes.
- [ ] Concluir o Bootcamp e construir um portfólio para oportunidades em Back-End.

---

## ⏱️ Carga Horária e Meta
- **Dedicação:** 10 horas semanais (2 horas por dia, de segunda a sexta)
- **Metodologia:** Teoria aplicada com prática direta no código e projetos.

---

## 📅 Cronograma Semanal de Conteúdos

### 🔹 Semana 1: Configuração do Ambiente, Git & Fundamentos do Java
- **Conteúdos da Semana:**
  - Configuração do JDK, IDE (IntelliJ / VS Code) e Git/GitHub.
  - Sintaxe básica do Java: Variáveis, Tipos de Dados Primitivos e Operadores.
  - Estruturas condicionais (`if`, `else`, `switch-case`).
  - Estruturas de repetição (`for`, `while`, `do-while`).
- **Entregável:** Repositório inicial configurado e resolução de exercícios básicos de controle de fluxo.

---

### 🔹 Semana 2: Programação Orientada a Objetos (POO) em Java
- **Conteúdos da Semana:**
  - Paradigma de Orientação a Objetos: Classes, Objetos, Atributos e Métodos.
  - Modificadores de Acesso, Encapsulamento, Getters e Setters.
  - Pilares de POO: Herança, Abstração, Polimorfismo e Interfaces.
  - Tratamento de Exceções (`try-catch-finally` e exceções personalizadas).
- **Entregável:** Projeto de modelagem POO (ex: Sistema Bancário ou Desafio da DIO).

---

### 🔹 Semana 3: Collections Framework & Stream API
- **Conteúdos da Semana:**
  - Estrutura de dados em Java: `List` (ArrayList), `Set` (HashSet) e `Map` (HashMap).
  - Iteração e manipulação avançada de coleções.
  - Introdução a Expressões Lambda.
  - Manipulação de dados com Stream API (filtros, mapeamento e ordenação).
- **Entregável:** Repositório com exemplos práticos de manipulação de coleções de dados.

---

### 🔹 Semana 4: Banco de Dados Relacional & Persistência (SQL e JPA)
- **Conteúdos da Semana:**
  - Fundamentos de Banco de Dados Relacional e linguagem SQL (DDL e DML).
  - Relacionamentos (1:1, 1:N, N:M) e comandos `JOIN`.
  - Conectividade Java via JDBC.
  - Mapeamento Objeto-Relacional (ORM) com JPA / Hibernate.
- **Entregável:** Script SQL de modelagem e aplicação Java integrada com banco de dados.

---

### 🔹 Semana 5: Ecossistema Spring Boot & Desenvolvimento de APIs REST
- **Conteúdos da Semana:**
  - Conceitos do Spring Boot, Inversão de Controle (IoC) e Injeção de Dependências.
  - Arquitetura MVC e criação de Endpoints RESTful (`@RestController`, `@RequestMapping`).
  - Camada de Serviço (`@Service`) e Regras de Negócio.
  - Validação de dados de entrada e tratamento global de erros.
  - Documentação de APIs com Swagger/OpenAPI.
- **Entregável:** API REST funcional com operações completas de CRUD.

---

### 🔹 Semana 6: Inteligência Artificial Aplicada ao Back-End
- **Conteúdos da Semana:**
  - Conceitos de IA Generativa, Prompts e consumo de APIs de IA em aplicações Java.
  - Introdução ao ecossistema **Spring AI**.
  - Configuração de credenciais, chaves e integração com modelos LLM (ex: OpenAI API).
  - Desenvolvimento de recursos inteligentes em APIs (geração de conteúdo, resumos ou recomendações).
- **Entregável:** API REST em Spring Boot integrada a um serviço de Inteligência Artificial.

---

### 🔹 Semana 7: Testes Automatizados & Boas Práticas (Clean Code)
- **Conteúdos da Semana:**
  - Conceitos e importância dos Testes Automatizados no Back-End.
  - Testes Unitários com **JUnit 5**.
  - Criação de Mocks para dependências usando **Mockito**.
  - Princípios de Clean Code e aplicação inicial dos conceitos SOLID.
- **Entregável:** Suíte de testes unitários integrada ao projeto da API Spring.

---

### 🔹 Semana 8: Projeto Final do Bootcamp & Consolidação de Portfólio
- **Conteúdos da Semana:**
  - Finalização e refatoração do Projeto Desafio Principal do Itaú.
  - Documentação técnica do projeto (`README.md`, arquitetura, instruções de execução e diagramas).
  - Submissão e validação do projeto na plataforma DIO.
  - Organização do perfil no GitHub e publicação da conquista no LinkedIn.
- **Entregável:** Projeto final publicado, documentado e Certificado do Bootcamp concluído.

### 💡 Dicas de Ouro para o seu Sucesso no Bootcamp

1. **Suba código todos os dias:** Mesmo que seja um programa simples de 10 linhas, faça o *commit* no seu GitHub. Isso constrói o hábito e deixa seu perfil verde no GitHub.
2. **Não apenas assista às aulas:** Escreva os códigos junto com os instrutores da DIO. Quando encontrar erros, leia a mensagem no console — aprender a ler *stack traces* é metade do trabalho de um Dev Back-End.
3. **Aproveite a IA a seu favor:** Use o ChatGPT/Copilot para explicar conceitos abstratos (como *"Explique polimorfismo em Java com uma analogia simples"*), mas evite pedir para a IA resolver os desafios de código por você sem antes tentar bastante.
